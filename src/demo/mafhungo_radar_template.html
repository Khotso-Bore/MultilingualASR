This page runs a small TF-IDF and logistic regression model, not the actual research model. The project's real, reported misinformation classifier is AfroXLM-RoBERTa, a 278 million parameter transformer, too large to run inside a webpage with no backend attached. Both models are trained on the exact same 358-article dataset, so the comparison above is apples to apples: this lightweight browser version and the real transformer land in the same range, around 56 to 58 percent accuracy on this task.

The training data is real Tshivenda government news from Vukuzenzele, paired with synthetic fake counterparts built by distorting numbers, dates, names, and one sentence per article. There is no dataset of real, organic Tshivenda misinformation to train on, the original Mukwevho et al. dataset this project was meant to use has been permanently lost. So a verdict here reflects whether text matches the pattern of this specific fact-distortion method, not general truthfulness.

The word highlighting above shows exactly why the model reached its verdict: it is a linear model over word frequencies, so every word's contribution to the score can be shown honestly, nothing hidden in a black box.

Built on top of the Tshivenda ASR and misinformation detection sub-study, COS700, University of Pretoria.
